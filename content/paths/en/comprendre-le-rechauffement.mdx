This path assumes no prior knowledge. It follows the order in which the ideas build on one
another: vocabulary first, measurement next, and only at the end the original scientific
publication.

If you take away one thing: climate science almost always handles **departures** from a
reference, never absolute values. That is the thread running through all six steps.
